# autoscalers-view

**ID:** autoscalers-view
**Spec:** Settled
**Implementation:** Complete

The Autoscalers page (`/autoscalers`): a read-only, sortable, searchable table of the horizontal pod autoscalers (HPAs) in the active context, showing how each is performing against its target metric and its replica bounds, plus each HPA's own detail page (`/autoscalers/:namespace/:name`) with its metrics, conditions, labels, annotations and raw YAML.

## Sub-features
None.
